# Banking app tree test

A ready-to-run tree test for a mobile banking app. It checks whether customers can find everyday tasks, like freezing a card or downloading a statement, in a typical app's navigation.

| | |
| --- | --- |
| Study type | Tree test |
| Tests | Navigation for accounts, payments, cards, insights, help and profile settings |
| Tasks | 7 |
| Suggested participants | 30 to 50 |
| Time per participant | About 5 minutes |

## When to use it

Use it when you're adding features to an app and need to decide where they live, or when support requests suggest people can't find things that already exist. Some of these tasks are urgent in real life (a lost card, a payment you don't recognise), so they're a good test of whether the app works under pressure.

## How to run it in tilia

1. Download this file.
2. In tilia, choose **+ New study**, then **Tree testing**, and click **import a markdown file**.
3. Upload this file. tilia reads only the tree below and ignores the rest.
4. Add the tasks below under **Tasks**, choosing each correct answer in the tree.
5. Publish the study and share the link with participants.

## Tasks

Each task describes a goal without using the words in the tree, so participants have to think about where things belong rather than match words.

1. You can't find your bank card but you think it's somewhere at home. You want to stop anyone using it for now. Where would you go?
   Correct answer: Cards › Freeze card
2. You cancelled your gym membership, but they've taken a payment from your card again this month. Where would you go to get the money back?
   Correct answer: Help › Dispute a transaction
3. A letting agent wants a recent bank statement as proof of address. Where would you find one?
   Correct answers: Accounts › Current account › Statements, or Profile › Documents
4. You've moved out of your flat and need to stop the rent you send your old landlord on the 1st of each month. Where would you go?
   Correct answer: Payments › Standing orders
5. Your new employer has asked for your sort code and account number. Where would you find them?
   Correct answer: Accounts › Current account › Account details
6. You want to know how much you spent on takeaways last month. Where would you look?
   Correct answer: Insights › Spending by category
7. You've got a new phone and want to log in without typing your code each time. Where would you set this up?
   Correct answer: Profile › Security › Face ID and fingerprint

## Adapting it

Swap the labels for your own app's navigation, keeping the depth roughly the same. Base tasks on your most common support requests. Keep tasks to 10 or fewer and turn on random task order in the study's **Settings** tab.

Task 3 has two correct answers on purpose. If a task could reasonably be answered in two places, mark both as correct. A tree test measures whether people can find things, not whether they pick the one place you had in mind.

## Reading the results

tilia shows a success rate for each task: the share of participants who chose a correct answer. It also splits results into direct success (they went straight to the answer) and indirect success (they got there after going back up the tree). Watch the urgent tasks (1 and 2) closely: indirect success there means people are hunting at exactly the moment they're most stressed.
