# University website tree test

A ready-to-run tree test for a university website. It checks whether prospective students, current students and visitors can find key information in a typical UK university's navigation.

| | |
| --- | --- |
| Study type | Tree test |
| Tests | Navigation for courses, fees, student life, support and research |
| Tasks | 7 |
| Suggested participants | 30 to 50 |
| Time per participant | About 5 minutes |

## When to use it

Use it before a website redesign to find out which parts of the current structure work, or to compare a proposed structure against the one you have now. Run the same tasks on both trees and compare the results.

It's also a realistic example for teaching information architecture: most students have used a university website recently and can judge the labels for themselves.

## How to run it in tilia

1. Download this file.
2. In tilia, choose **+ New study**, then **Tree testing**, and click **import a markdown file**.
3. Upload this file. tilia reads only the tree below and ignores the rest.
4. Add the tasks below under **Tasks**, choosing each correct answer in the tree.
5. Publish the study and share the link with participants.

## Tasks

Each task describes a goal without using the words in the tree, so participants have to think about where things belong rather than match words.

1. You're in sixth form and want to visit the campus before you apply. Where would you find out when you can come?
   Correct answer: Study › Undergraduate › Open days
2. You've been offered a place and want to know if there's money available that you won't have to pay back. Where would you look?
   Correct answer: Fees and funding › Scholarships and bursaries
3. You're a first-year student, you've been feeling low for a few weeks and you'd like to talk to someone. Where would you go?
   Correct answer: Support › Wellbeing and counselling
4. You've just finished a master's and want to do a PhD here. Where would you start?
   Correct answer: Study › Postgraduate › Research degrees
5. You're a journalist writing about flooding and want to interview an academic who studies it. Where would you look?
   Correct answer: Research › Find an expert
6. Your second fee instalment is due next week. Where would you go to sort it out?
   Correct answer: Fees and funding › Paying your fees
7. Your halls contract ends in June and you want to find a shared house for second year. Where would you look?
   Correct answer: Student life › Accommodation › Private housing

## Adapting it

Swap the labels for your own university's navigation, keeping the depth roughly the same. Keep tasks to 10 or fewer so participants don't get tired, and order them differently from the tree so the order doesn't give answers away. You can also turn on random task order in the study's **Settings** tab.

If a task could reasonably be answered in two places, mark both as correct. A tree test measures whether people can find things, not whether they pick the one place you had in mind.

## Reading the results

tilia shows a success rate for each task: the share of participants who chose a correct answer. It also splits results into direct success (they went straight to the answer) and indirect success (they got there after going back up the tree). Lots of indirect success suggests the right place exists but the labels on the way to it aren't clear.
