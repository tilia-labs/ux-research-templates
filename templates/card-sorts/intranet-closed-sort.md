# Intranet closed card sort

A ready-to-run closed card sort for a company intranet. Participants sort 30 common intranet pages into 6 proposed sections, which tests whether a new structure makes sense to staff before you build it.

| | |
| --- | --- |
| Study type | Card sort (closed) |
| Tests | Whether staff agree on where intranet pages belong |
| Cards | 30 |
| Categories | 6 |
| Suggested participants | 20 to 40 |
| Time per participant | About 10 minutes |

## When to use it

Use a closed sort once you have a proposed structure and want to check it. Intranets often grow around departments (HR, Finance, IT, Facilities), but staff look for things by what they're trying to do. This sort shows where those two views clash, for example whether "Parental leave policy" feels like an HR page or a "Money" page.

## How to run it in tilia

1. Download this file.
2. In tilia, choose **+ New study**, then **Card sort**, and select **Closed sort**.
3. Click **import a markdown file** and upload this file. tilia reads only the cards below and ignores the rest.
4. Add the 6 categories below under **Categories**.
5. Turn on random card order in the study's **Settings** tab, so cards near the top of the list don't get sorted more carefully than the rest.
6. Publish the study and share the link with participants.

## Adapting it

Replace the cards with your own intranet's most visited pages, and the categories with the structure you're proposing. Keep categories to 8 or fewer. If you're unsure what the categories should be, run an open sort first and use the group names people come up with.

## Reading the results

For each card, look at how strongly participants agreed on a category. Cards with clear agreement are in the right place. Cards split between two categories might need to appear in both, or might need renaming. If one category attracts lots of unrelated cards, its name is probably too broad.
