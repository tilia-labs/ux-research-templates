# UX research templates

Free, ready-to-run tree test and card sort templates for UX designers and researchers. Each one is a markdown file you can upload to [tilia](https://tilialabs.io/?utm_source=github&utm_medium=readme&utm_campaign=intro), an async UX research tool, and have a study live in about five minutes.

## Quick start

1. Pick a template below and download the file.
2. In tilia, start a new tree test or card sort and click **import a markdown file**.
3. Add the tasks or categories listed in the template, publish, and share the link.

Every template includes guidance on when to use it, how many participants to recruit, how to adapt it and how to read the results. They're worth reading even if you run your studies somewhere else.

## Templates

### Tree tests

A tree test checks whether people can find things in your navigation, using only the labels, without the visual design getting in the way.

| Template | Use it to |
| --- | --- |
| [University website](templates/tree-tests/university-website.md) | Test how prospective and current students find courses, fees and support |
| [Local council website](templates/tree-tests/local-council-website.md) | Test how residents find everyday services, from bins to Council Tax |
| [Banking app](templates/tree-tests/banking-app.md) | Test how customers find urgent and everyday tasks in a mobile app |
| [Help centre](templates/tree-tests/help-centre.md) | Test whether customers can find the right support article |

### Card sorts

A card sort asks people to group content. In an open sort they name their own groups. In a closed sort they use categories you've set.

| Template | Use it to |
| --- | --- |
| [Recipe website (open)](templates/card-sorts/recipe-site-open-sort.md) | Find out how home cooks naturally group recipes, guides and tips |
| [Intranet (closed)](templates/card-sorts/intranet-closed-sort.md) | Check whether staff agree with a proposed intranet structure |

## Writing your own

tilia imports trees and cards from simple bullet lists. The [markdown format guide](docs/markdown-format.md) explains exactly what the import reads, what it ignores and the common mistakes to avoid.
